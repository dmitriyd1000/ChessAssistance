This application, based on BerdChess, enhances its capabilities by adding new features. The key addition is the ability to recognize a chess position from a screen. This functionality supports multiple displays.
To capture a screenshot, select the menu item Game -> Get Board from new screen (Hotkey G). You will then need to adjust the borders of the yellow form to fully cover the desired position on your screen. Double-clicking the yellow form initiates the processing.
![Screenshot 2024-07-20 122140](https://github.com/user-attachments/assets/bdda84c8-8158-453e-afd2-ce716a5bf017)
f the coordinates remain unchanged, you can repeat the screenshot capture from the same position by selecting Game -> Get Board from prev screen (Hotkey Ctrl + G). Once the position is transferred to BerdChess's board, you can calculate your moves.
![Screenshot 2024-07-20 234449](https://github.com/user-attachments/assets/54442808-1bbd-437d-98e4-096eefb018f5)
Additionally, you can integrate a chess engine to check or find the sharpest moves.
